# EstateHub AI – Agentic Multi-Agent Real Estate Assistant

## Problem Statement
Property discovery can require separate searches for listings, location information, site visits and affordability calculations.

## Objective
Build an agentic assistant that converts a property requirement into a structured property-search and site-visit plan.

## Agents
Orchestrator, Property Search, Area Insights, Site Visit, Affordability and Validation agents.

## Tools
Property Search Tool, Area Insights Tool, Visit Scheduling Tool and Loan/Affordability Tool.

## Database
Clients, property inquiries and search history are persisted with SQLite and SQLAlchemy.

## Safety and Accuracy
Demo mode uses mock property data. Listing availability, ownership, title, approvals, legal documents, market prices, taxes and financing terms must be independently verified before a transaction.

## Future Scope
Real property listing APIs, maps, mortgage providers, document verification, CRM integration, lead scoring, multilingual support and secure authentication.
